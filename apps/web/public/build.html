INSTALLATION GUIDE

安装、恢复与迁移

首次使用按顺序激活；重新部署时，按实际场景选择处理方式。

操作指南
START HERE

首次安装 · 三步完成激活

点击开始激活后计时 60 分钟
  1. 01

    安装主题包

    上传构建好的 ZIP，确认授权桥已安装并启用。

  2. 02

    本地解锁

    点击“开始激活”，输入与此安装包对应的一次性 Install Key。

  3. 03

    在线激活

    进入主题后台，输入固定 License Key，完成授权后使用。

RECOVERY & CHANGES

已有安装，按场景处理

固定 Key 与安装身份分别管理
↻

同服务器重装 / 修复

保留安装身份与私钥，校验官方包后恢复授权。修复覆盖同版本程序文件，保留用户数据。

保留 Installation ID · 刷新凭证可轮换
↗

更换授权域名

在“我的授权”自助换绑，再为新域名重新构建并激活。旧激活撤销，固定 Key 保持不变。

旧包不能跨域复制使用
⇄

迁移到新服务器

新服务器生成新安装身份，通过迁移配对和验证完成接管。切换后隔离旧安装，并保留回滚窗口。

仅一个活动实例 · 本页为流程说明
◇

离线授权文件

由已激活服务器申请签名文件，绑定域名、安装包、套餐及有效期；不能复制到其他服务器使用。

由安装私钥申请 · 到期需重新验证
60 分钟窗口

刷新页面或输错 Key 不会重置计时。超时后主题保持锁定，服务端桥先切回原主题，再清理未激活主题，保留业务数据。

确认后立即换绑；旧域名授权随即失效，新域名需重新输入原固定 Key 激活。

i
固定 Key 不会变化

域名换绑不会删除授权、源码或业务数据。旧激活会立即失效，新域名本地源码需要重新输入原固定 Key 完成激活。
