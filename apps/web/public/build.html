PRODUCT LIFECYCLE

安装、恢复与迁移

所有操作共用同一固定 License Key，但安装身份和一次性凭证严格分离。

安全状态机
01
FIRST INSTALL

首次安装激活

安装 ZIP 后点击“开始激活”才启动 60 分钟窗口。先使用一次性 Install Key 解锁，再使用固定 License Key 完成正式激活。

02
REINSTALL & REPAIR

同服务器重装 / 修复

保留 Installation ID 与安装私钥时，可验证官方包后恢复授权并轮换刷新凭证；修复只覆盖同版本程序文件，不改变用户数据。

03
DOMAIN REBIND

更换授权域名

在“我的授权”自助换绑。旧激活立即撤销，固定 Key 不变；随后为新域名重新构建并激活，避免旧包跨域复制。

04
SERVER MIGRATION

迁移到新服务器

新服务器必须生成新的 Installation ID。迁移采用短期配对、候选验证、唯一 Active 切换与回滚窗口，旧服务器切换后进入 Fenced。

05
OFFLINE LICENSE

离线授权文件

由已激活服务器使用安装私钥申请签名文件；文件绑定域名、Build、Package、套餐和离线截止时间，不能复制到另一台服务器。

60
MINUTE WINDOW

超时安全清理

倒计时不因刷新或输错 Key 重置。超时后主题保持锁定，并由 Xboard 服务端桥先切回原主题再删除未激活主题，绝不删除业务数据。

i
服务端桥是安全边界

自动删除、服务器身份恢复、离线文件和迁移签名必须由 Xboard 服务端桥执行；浏览器 JS 只负责展示与发起受控请求。
