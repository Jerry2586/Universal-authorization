# APPGOG License Bridge

该插件随 APPGOG 客户专属主题包交付。已登录的 Xboard 管理员第一次打开客户主题时，主题运行时会校验插件 ZIP 摘要，并通过 Xboard 官方插件接口自动上传、安装、启用和检查本插件；健康检查通过后才允许开始 60 分钟激活窗口。插件只负责 Xboard 服务端授权边界：

- 持久化 Ed25519 Installation Identity；
- 对 APPGOG 一次性 Challenge 进行受限签名；
- 使用 Laravel `APP_KEY` 加密保存激活与刷新状态；
- 保存安装前主题，并在激活窗口超时后先切回再删除当前 APPGOG 主题；
- 为同机恢复、离线授权和受控迁机保留同一服务器身份。

插件不删除 Xboard 数据库、用户数据、其他主题或业务文件。

插件 API 全部受限流保护。包注册、Installation Challenge 签名和完整状态读写必须通过 Xboard 管理员身份；普通主题浏览器只能携带客户包证明读取不含密钥的运行状态、触发服务端授权刷新，或在窗口到期时请求插件再次向授权中心确认后安全切回并删除主题。Xboard 管理令牌只用于同源官方插件接口，不会发送到 APPGOG 授权中心。
