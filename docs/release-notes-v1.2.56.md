# APPGOG打包授权系统 v1.2.56

- 把产品源码与客户保护成品彻底分层：官方产品 Git 和上传源 ZIP 保持原生态明文，授权桥、客户身份、水印、签名、JS/CSS 混淆只在 Worker 隔离构建副本中生成。
- 发布源版本时拒绝客户加密成品、授权运行时、桥 ZIP、客户构建清单和水印特征；源 ZIP 落盘后校验 SHA-256，构建完成前再次读取并核对摘要，发现任何回写即终止交付。
- 最终成品不只信任清单声明，实际检查生成授权运行时与桥内 JavaScript 的保护标记、按身份派生的混淆标识、紧凑输出和 Source Map 禁令；伪造标记或明文脚本无法交付。
- 授权桥升级至 1.1.7，通过唯一迁移 `2026_09_29_000014_generated_js_protection` 刷新宿主运行时，同时保留安装身份、激活、私有状态、已登记公钥和恢复备份。
- 继承 v1.2.55 的套餐版本关联、门户一致性、实时构建进度、在线更新和数据保留规则；不重签客户 Key，不修改授权域名或 Installation ID，不覆盖历史构建与备份。

## 回归与发布边界

回归覆盖完整构建、源 ZIP 构建前后逐字节不变、客户成品拒绝回传为源码、构建期间源包被改写时失败、运行时/桥脚本明文篡改拒绝、独立 Worker、桥迁移和两阶段激活。正式发布仍须通过全量测试、发布合同、Docker 首装/升级/恢复、七附件签名与 GitHub Release 回下载验证。
