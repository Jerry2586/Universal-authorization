# 安全项目剥离

APPGOG v1.2.70 维护授权、打包及其业务运维。铁幕安全本地服务与玄武引擎云端服务在 Jerry2586/Cloud-based-Scanning-and-Removal-Center 独立维护，使用独立配置、数据库、身份和发布版本。

## 升级行为

- 管理后台移除安全查杀导航与页面，原安全 HTTP 接口撤销。
- 三种业务安装角色、业务配对、授权签名、客户保护、备份、迁移与安全更新继续保留。
- Compose 不再挂载本地安全 socket 或安全状态目录；业务容器保留非 root、只读文件系统和权限收敛。
- 本项目不删除 /etc/appgog-security、/var/lib/appgog-security、旧 systemd 安全服务或其证据。历史服务及证据由管理员核实、归档后按独立项目迁移说明处理；APPGOG 的运行不要求安装独立安全项目。
- 旧 incident.json 围栏存在时禁止更新或重启业务，不会自动解封。安装器保留明确错误提示，不调用已迁走的安全脚本。管理员须先确认入侵原因已排除、业务恢复点可信，并将事件记录归档到受保护的位置后人工解除历史围栏；不得以直接删除记录替代调查和修复。

## 数据边界

不修改业务数据库、管理员、客户 Key、激活身份、上传、构建成品、备份或签名密钥。安全监测身份不作为业务授权凭据，也不参与授权决定。独立安全项目可保护 APPGOG 或其它网站。

## 验收

验证移除的两个安全 API 返回 404，验证授权、打包、Worker、分机配对、备份、迁移与签名更新回归。Linux Docker 首装和旧版本升级必须由 CI 或真实受支持主机验证；Windows 源码测试不替代这些验收。
