# APPGOG打包授权系统 v1.2.19

日期：2026-09-25

本地修复版本，尚未生成正式发布附件或创建 GitHub Release。包含 v1.2.18 的连通性修复。

- 管理中心与独立打包中心的登录页、登录后侧栏显示各自运行进程的版本，统一来自 package.json；不再使用上游版本覆盖本地侧栏。
- HTML 与 HTTP 响应提供运行版本；版本在进程启动时读取，磁盘更新不会使旧进程冒充新版。
- 独立打包中心健康接口返回 version 和 upstream_version；两端版本不同或上游缺少版本时返回 503 / VERSION_MISMATCH，明确提示同步升级并重启。
- 增加真实 HTTP 回归：管理账号、授权 Key、域名和套餐、公告与节点、工单及附件隔离、版本发布撤回、更新请求、迁移接收入口、安装解锁与激活续期。
- 保留静态 ES Module 白名单、代理请求上下文、就绪检查、拆分启动与端口校验修复。

源码修复不改变真实数据库、账号、Key、签名身份或 release-contract.json。真实更新/迁移助手、Docker、Linux 安装器、正式制品和 CI 必须按发布政策另行验证；本地接口回归不能替代生产验收。
