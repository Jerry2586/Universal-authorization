# APPGOG打包授权系统 v1.2.9

发布日期：2026-09-25

## 本次修复

- 修复管理菜单第 9 项“安全更新最新版本”在已有安装上仍执行首装 DNS A 记录归属检查，导致域名经过代理、负载均衡或解析到其他公网入口时升级被错误终止的问题。
- 已有系统升级现在读取并保留 `/opt/appgog/shared/.env` 中的现有域名，跳过首装专用的 DNS 指向强制匹配。
- 首次安装仍严格检查两个域名是否解析到当前服务器公网 IPv4，避免新安装在错误 DNS 下启动。
- 升级流程继续执行发布签名与 SHA-256 校验、完整备份、基础镜像环境探测、容器健康检查、公网 HTTPS 检查和失败自动恢复。

## 数据与升级

本版本不修改业务数据库结构。管理员账号和密码、授权 Key、公告、运营设置、工单、签名密钥、上传源码、构建成品、日志和备份全部保留；只覆盖程序源码、安装器和文档。

服务器重新选择菜单第 9 项或执行 `appgog update` 即可升级到 v1.2.9，不需要修改现有 DNS，也不需要重新输入 Git Key。
