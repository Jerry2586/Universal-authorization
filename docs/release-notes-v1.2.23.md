# APPGOG打包授权系统 v1.2.23

日期：2026-09-25

## 自动签名发布

- main 分支验证成功后自动使用隔离的 Ed25519 发布密钥生成正式 ZIP、`.run`、SHA-256、稳定 `install.sh`、清单和签名；
- 自动创建不可变 `v1.2.23` 标签和 GitHub Latest Release，标签已存在时必须指向同一提交，否则发布失败；
- Release 创建后从 GitHub 回下载固定七附件，重新验证 Latest 状态、附件数量、签名、哈希和包内版本；
- 新增每日发布漂移检查，确保 main、清单、安装包与 Latest Release 始终属于同一版本。

## 在线更新防漂移

- 更新助手状态升级为 schema 2，独立记录进程心跳、Release 检查时间、检查结果、签名来源和错误；
- Release 检查失败会清空当前最新版本，只保留历史成功版本用于诊断，不再把旧版本显示成“最新”；
- 检查结果超过一小时自动视为过期；发布源落后于当前运行版本时显示明确警告并禁止更新；
- 只有助手在线、检查结果新鲜、签名有效且确有更高版本时，“安全更新最新版本”才可点击。

## 数据兼容

本版本只覆盖程序源码、页面、更新助手和发布流水线。数据库、管理员账号和密码、授权 Key、公告、设置、签名身份、上传、构建成品、日志和备份继续原样保留。
