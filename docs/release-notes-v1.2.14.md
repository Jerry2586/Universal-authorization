# APPGOG打包授权系统 v1.2.14

日期：2026-09-25

## 本次交付

v1.2.14 完成公司级重构蓝图 Phase 4，把授权生命周期、永久删除补偿和工单附件权限收敛为可审计、可恢复、可验证的固定边界。

- 管理后台的每条授权新增“事件记录”，统一展示签发、Key 轮换/查看、套餐、状态、域名绑定/迁移、构建和激活事件；
- 授权事件查询只要求 `license.view`，只读审计员可以查看，不能借此修改授权；
- 事件 `metadata_json` 只在服务端解析，Key、Secret、Token、密码和凭证类字段递归替换为 `[REDACTED]`，响应不返回原始 JSON 字段；
- License 永久删除时，无法立即删除的上传、附件或成品进入 `file_cleanup_tasks` 补偿队列；容器启动与平台所有者手动接口都可幂等重试；
- 补偿文件全部清理后，匿名 Tombstone 自动从 `completed_with_cleanup_pending` 收敛为 `completed`，不恢复已删除的客户身份数据；
- 工单附件新增 `public/internal` 可见性与上传者身份。客户附件始终公开给双方，管理员内部附件只在管理端显示和下载；
- 工单关闭后禁止继续上传附件；管理员内部备注的附件与备注使用同一可见性，前端上传参数不会再被文件名查询参数覆盖；
- 老数据库通过可重复增列迁移获得新字段，历史附件默认 `public`，管理员、客户、Key、工单和文件记录保持不变。

## 兼容与升级

- `/api/v1`、既有 `/web/*` 请求字段、Cookie、CSRF、角色权限和安装命令保持兼容；
- 程序源码、前端、后端、Docker 和安装器按 v1.2.14 完整覆盖，数据库和共享数据目录原地保留；
- 不清库、不删卷、不轮换已有 License Key、管理员密码或三类生产签名密钥；
- 升级失败仍保存独立诊断日志并自动恢复原健康版本。

## 验证

- 回归覆盖内部附件列表隔离、直接下载拦截、客户附件强制公开和关闭后禁止上传；
- 回归覆盖只读审计权限、授权事件脱敏和响应不包含完整 License Key；
- 回归覆盖永久删除文件失败、补偿任务登记、手动重试、Tombstone 收敛和重复重试幂等；
- 回归覆盖旧 `support_attachments`、`file_cleanup_tasks` 表增列并保留历史记录；
- 正式发布继续要求全量测试、Shell 语法、源码/制品合同、Ubuntu/Docker CI、七附件回下载和 Ed25519/SHA-256 复验全部通过。
