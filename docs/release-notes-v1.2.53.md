# APPGOG打包授权系统 v1.2.53

发布日期：2026-09-28

## 在线更新实时状态

- 检查更新、安全更新和修复当前版本会绑定本次任务 ID，持续显示排队、执行、服务重启和最终结果，不再只在点击后读取一次状态。
- 更新或修复期间即使 Web 服务短暂断开，页面会保持自动重连，不把正常重启误报为需要人工刷新。
- 安全更新和修复成功后自动刷新当前页面，重新加载新版前端资源、运行版本和按钮状态；检查更新完成后直接更新最新版本信息，不重载页面。

## 打包进度实时刷新

- 运营中心和客户打包中心共用动态刷新调度：有排队或构建中任务时每 2 秒刷新，全部完成后恢复 15 秒常规刷新。
- 首次状态尚未抓到、任务刚进入队列或一次网络请求失败，都不会终止后续轮询。
- 打包历史已打开时同步合并最新任务状态和进度，避免列表停留在旧百分比直到手动刷新。

## 兼容与数据边界

本次只调整门户状态同步与更新任务跟踪，不改变授权 Key、套餐权益、激活、域名、数据库、签名密钥、构建成品或备份。授权桥保持 1.1.6，环境合同不变。
