# APPGOG打包授权系统 v1.2.65

- 保留原授权、打包、Worker 同机签名一键安装。
- 同一签名 `.run` 支持授权机和打包机分别一键安装。打包机首次启动进入待配对状态，仅响应健康检查。
- 授权机 Linux 菜单签发独立节点凭据，打包机菜单验证 HTTPS、版本、双节点身份并导入；失败回滚原配置。
- 分机 DNS 自动配置只修改本机域名；各机的卸载菜单保留本机数据。
- 云端安全中心和本地查杀入口仍在菜单 17；正式生产需要完成两机 Linux 及云端实机验收。
- 分机菜单按角色限制授权控制中心操作；CI 增加独立授权与未配对打包容器的启动、隔离及 503 验证。
