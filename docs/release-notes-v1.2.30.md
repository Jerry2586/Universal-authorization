# APPGOG打包授权系统 v1.2.30

日期：2026-09-26

- 修复主题安装解锁后丢失已识别 Xboard 管理路径的问题，安装凭据与固定 Key 激活之间保留安装身份和窗口上下文。固定 Key 激活后从浏览器状态移除安装凭据密文、刷新密钥和窗口 Token，服务端桥继续保留所需状态。
- 三个客户主题入口在授权运行时及网络检查开始前锁定内容，验证成功再显示原页面，避免后台先闪现。
- 授权桥 HTTP 429、5xx 和网络失败不再误判为组件缺失，不重复上传或安装插件。
- 授权桥更新为 1.0.2：迁移在 Xboard 提交并启用升级后尝试通过官方 Octane 命令重载 Worker，仅清理本插件 PHP 缓存，保留 Installation ID 与授权状态。运行时通过健康接口确认实际版本；未生效时保持锁定并明确提示重载应用服务。
- 增加两阶段状态衔接、服务异常不重装、入口预锁定和桥升级重载回归测试。
- 保持固定 Key → 域名与 Installation ID 校验、一次性 Install Key → Install Receipt → 固定 Key 的现有授权边界；升级保留数据库、账号、密钥、授权、设置、上传和构建。环境依赖继续遵循 release-contract.json。

验收范围：本版本修复真实打包安装与两阶段激活链路。未激活安装的过期清理仍依赖 Xboard 授权桥和调度器；离线撤销即时性、已激活后撤销宽限期自动删除、原生主题卡片按钮定制不在本次完成范围。不能将前端锁定或混淆当作所有服务端业务接口的授权防线。
