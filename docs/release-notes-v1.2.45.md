# APPGOG打包授权系统 v1.2.45

## 打包与界面

- 按确认截图恢复最新/当前版本左右双卡布局，下方构建记录独立展示；窄屏单列，统一边框、间距、主次按钮及中文状态。修复交付步骤 details 标签错误闭合导致总览与打包页串在一起，记录行按钮增加间距。
- 打包中心新增独立历史记录入口，版本面板可直达。按会话授权隔离，稳定游标分页覆盖超过 30 条的旧任务，支持版本、域名和构建编号搜索，展示结果、时间与激活状态。
- 主动作废未使用成品时，撤销包与安装 Key、作废状态、一次性返还标记及审计在同一事务完成。总消耗和滚动 24 小时消耗同步减少；排队任务无消耗不增加额度，已解锁/激活包不能作废，重复请求不重复返还。历史已作废任务不做未经确认的批量回填。

## 固定授权桥组件维护

- 移除 Xboard 地址、账号、密码与连接表单；只提供当前版本、最新版本、检查版本、更新和修复。固定源为本仓库正式 GitHub Release。
- 更新验证 Ed25519 发布清单、平台 ZIP 摘要和桥描述后，将证据写入持久组件目录并原子切换。更新只接受更高桥版本；修复重新下载当前组件对应的正式发布版本，拒绝降级。
- 本机构建与独立 Worker 使用同一组件来源。Worker 使用独立包签名密钥验证绑定构建、签发者和有效期的组件快照；拒绝缺失、过期或被替换的组件。
- 更新桥组件不直接升级客户已部署的插件。持久目录随业务制品备份保留，系统升级自带更高桥版本时不会被旧覆盖组件锁定。

## 授权桥 1.1.4 与激活弹窗

- 受保护主题移除原生“主题设置”和“激活主题”的显示，只保留底部“激活 / 授权管理”与原生删除入口；其他主题保持原操作。保留 React 所有的 DOM 节点，避免破坏宿主渲染。
- 新增独立迁移 000011，升级时刷新持久后台扩展并安排运行时重载，保留安装身份、授权和恢复备份。
- 弹窗采用固定标题栏与单一内层滚动，表单字号、间距和主次按钮统一，取消无用的禁用占位按钮。
- 插件 ZIP 请求附带 Build 和摘要缓存参数；非 ZIP 响应与摘要不一致给出分别诊断，拒绝上传并清除“正在上传”的旧状态。完整性校验没有放宽。

## 套餐与平台版本锁定

- 套餐管理集中创建、编辑、停用和删除套餐；授权页选择或切换套餐，已有授权的单独额度操作保留。删除保留历史引用和已签发权益快照，不能再签发已删除套餐；删除和审计在同一事务完成。
- 在线安全更新新增“锁定当前版本 / 解除版本锁定”。状态持久保存于 shared/update-control/version-lock.json，更新助手重启不清除；锁定后可检查更新和修复对应版本，网页、appgog update 与新版 .run 安装器拒绝切换到其他版本。
- 更新排队/执行期间不可切换锁定；API 和安装器共用版本变更互斥目录。损坏的锁定记录阻止版本部署；管理员在面板重新设置后恢复。锁定写入审计失败时补偿恢复原文件。
- root 手工修改文件或使用不认识锁定合同的历史安装器不属于锁定防护范围。

## 验证与部署范围

全量测试、真实主题 ZIP 构建回归、实际页面浏览器验证、发布合同、Shell 语法、签名制品与 Docker CI 按既有发布顺序执行。浏览器页面用隔离测试数据，不能据此声称线上服务器已更新或已排除全部现场网络与缓存问题。中心更新后新构建带入新运行时及桥，已经下载的旧包不被自动改写。
