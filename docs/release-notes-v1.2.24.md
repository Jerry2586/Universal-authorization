# APPGOG打包授权系统 v1.2.24

发布日期：2026-09-25

## 本次更新

- 在现有主题版本库增加发布权益，管理员上传 ZIP 时明确选择“免费授权可用”或“仅付费授权可用”；更新类型不会自动决定权益。
- 版本权益由 Entitlement 服务统一判断，并在公开打包授权、客户构建排队和 Worker 领取任务时重复校验，前端无法绕过。
- 免费授权可继续使用最新可用免费版本，同时能看到更高的付费版本和明确锁定原因；付费与历史兼容授权可使用两类版本。
- 旧数据库自动增加 `source_versions.access_tier`，既有版本默认 `free`，管理员、Key、激活、域名、设置、构建与文件数据全部保留。
- 平台名称通过只读品牌接口同步到管理员登录页、运营后台和客户打包中心；运营设置保存后回读并显示同步成功反馈。
- 新增版本权益、客户最新可用版本、接口绕过防护、旧库升级和动态品牌回归测试。

## 兼容性与安全边界

- 未修改固定 Key、两阶段安装解锁、正式激活、域名绑定、Installation ID、离线授权、撤销、删除和迁移状态机。
- 免费版本仍必须具备有效授权；授权暂停、收回、删除或过期后，免费与付费版本均不可构建或使用。
- Node、Caddy、Docker Compose、CPU 架构和签名发布合同与 v1.2.23 保持一致。
