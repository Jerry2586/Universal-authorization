## 需要目标项目源码后接入

- 仓库不包含真实 APPGOG/Xboard 后端源码，因此无法替目标项目虚构设置保存、主题启用、Xboard 连接、受保护资源和正式更新等每一条业务路由。
- 通用服务端守卫、capability 模型、激活 API、浏览器运行时和接入契约已经完成；取得目标源码后，应把 `activationGuard(...)` 接到所有关键服务端入口，并将 Refresh Secret、Activation ID 与 Installation ID 存入服务器不可公开访问的位置。
- 真实 Vue/npm 构建命令、Blade 路由、静态资源基准路径、安装目录结构、更新/重装和 Xboard 数据回滚必须针对目标源码验证。

## 安全边界

- 当前保护层能识别跨包替换和篡改，提高静态阅读、普通复制和批量滥用成本，并通过水印追踪包来源。
- ZIP 中最终需要执行的客户端代码仍处于客户控制环境；系统不承诺“绝对不可破解”或“运行态永远无法提取”。
- 未对未知第三方业务 JS/CSS 做激进控制流重写，以免破坏 Xboard 主题兼容性。根信任仍是服务端授权状态、Ed25519 签名、环境绑定、完整性验证和审计。

## 后续扩展，不是单机 v1.0.0 阻塞项

- PostgreSQL、Redis/专业队列、S3 兼容对象存储、KMS/Vault/HSM、多授权中心高可用、管理员 MFA、集中监控与告警。
- 本地 ArtifactStore 已使用短期、会话绑定 HMAC 下载票据；迁移到对象存储后可替换为对象存储原生短时签名 URL，不改变业务授权语义。
