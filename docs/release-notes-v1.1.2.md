# APPGOG打包授权系统 v1.1.2

发布日期：2026-09-24。

## 修复内容

- 修复一键安装器只比较磁盘 `package.json` 的问题。现在会同时核对运行中的 Docker 容器版本和健康状态。
- 当源码已经是当前版本、但容器仍运行旧镜像、容器停止或健康检查异常时，不再误报“已经最新”，而是自动进入安全修复和重新部署流程。
- 管理后台与客户中心的 HTML、CSS、JavaScript 等静态资源统一使用 `no-store`，更新后不会继续显示旧 UI。
- 管理后台“退出登录”改为右上角直接显示，与客户打包中心保持一致；用户中心保留为独立入口，不再把退出按钮藏在账号下拉菜单。
- 登录页继续保持无“返回首页”按钮和无隐藏点击区域。

## 验证

- 完整自动测试 66 项：64 项通过、0 项失败、2 项仅因 Windows 测试环境缺少 POSIX shell 跳过。
- 新增回归测试，锁定运行容器版本检查、异常容器自动修复、静态资源禁用缓存和右上角退出按钮。
