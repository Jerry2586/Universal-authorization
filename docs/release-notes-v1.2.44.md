# APPGOG打包授权系统 v1.2.44

## 打包额度与打包中心简化

- 授权中心及打包中心共用展示逻辑。当前可打包次数同时考虑总额度和滚动 24 小时上限，修复总额度耗尽但客户仍看到剩余次数的误导展示。
- 授权列表使用“当前可打包”作为主信息；额度弹窗分为当前剩余、用量明细及调整表单。总次数不限使用明确选项，并说明总额度包含已经使用的次数、24 小时上限不是零点重置。
- 保留未提交的额度输入和调整原因，普通数据刷新不再覆盖正在编辑的表单。
- 打包中心突出“开始打包”，额度明细、交付步骤和版本说明可展开查看。原下载、激活、工单和版本权限功能保持。
- 只调整页面投影与交互，服务端额度规则、原授权、套餐、安装身份、水印和成品目录命名不变。授权桥仍为 1.1.3；环境合同不变。

## 验证

新增有限/无限/耗尽/缺失字段的额度投影回归，以及实际页面的保存参数、刷新保留输入、明细展开和窄屏浏览器验证。按既有发布合同执行全量测试、签名制品及 Docker CI。
