# APPGOG打包授权系统 v1.2.34

日期：2026-09-26

- 继承 v1.2.33 的包级激活状态、可用交付操作、双端持久未读、管理路径兼容和主题授权入口。
- 实站连续请求发现 Xboard 在 HTTP 中间件内部才启动插件；启动时追加全局中间件不能保证当前请求执行，可能出现首次/刷新后台缺少授权入口。授权桥 1.0.6 改用 Laravel RequestHandled 响应事件扩展后台 HTML，不依赖下一次请求，也不修改 Xboard 核心文件。
- 新增唯一插件迁移触发 PHP 常驻进程重载；原有安装身份、私密状态和主题设置不变。
- 环境合同保持 Node 24 / Caddy 2.10。升级保留用户、密钥、数据库、工单、构建和配置。

边界沿用 v1.2.33：首次尚未安装桥时，Xboard 原生后台没有 APPGOG 扩展，需先通过已登录主题页准备插件；新主题运行时必须重构建安装，中心升级不能修改已交付 ZIP。全产品路由 Guard 和撤销后自动删除未在本次完成。

追加实站根因：Octane 的 CLI 命令在 HTTP 进程默认未注册；旧探测错误判为非 Octane。授权桥最终版本为 1.0.8，HTTP 维护与迁移回调显式注册官方 ReloadCommand，再请求重载。增加仅管理员可用、独立限流的固定重载接口，不接受命令参数。连续8次新请求确认同一新版本及入口。
