# APPGOG打包授权系统 v1.1.3

发布日期：2026-09-24。

## 修复内容

- 修复旧 Docker 镜像被重新创建后携带新 `APPGOG_VERSION` 环境变量，从而冒充新版本并跳过升级的问题。
- 一键引导器现在直接从正式容器内部读取 `/app/package.json`，以镜像中真实源码版本作为升级依据，不再信任外部环境变量。
- 当磁盘源码、容器环境变量和运行镜像版本不一致时，自动进入安全重建和部署流程。
- 修复授权中心 `/health` 长期硬编码返回 `1.0.0` 的问题；现在返回镜像内 `package.json` 的真实版本。

## 线上问题核验

- `sq.appgog.top/admin` 返回的页面与历史提交 `700a978` 完全一致，确认服务器实际仍在提供最初的 v1.0.0 页面。
- 本版本升级后，管理后台将显示右上角直接退出、用户中心、真实 ZIP 拖拽上传和当前版本的其他已发布功能。

## 验证

- 新增回归测试，验证引导器通过 `docker cp` 读取运行镜像真实版本。
