# APPGOG打包授权系统 v1.2.55

- 授权列表直接显示当前套餐名称，点击名称打开套餐切换窗口。长名称保持同宽并省略展示，悬停和弹窗显示完整名称。
- 两个中心的 HTML、JavaScript 模块及样式使用当前运行版本的资源路径，相对导入沿用同一版本路径，降低升级后新旧资源混用风险。
- 页面携带文档版本，和服务端版本不一致时加载带版本参数的新页面。持续返回旧页面时显示明确刷新入口并阻止旧发布表单提交，避免无限重载。
- 旧发布表单缺少套餐选择项或状态节点时明确提示升级页面，不再出现没有可选套餐却要求选择套餐的死路。

回归覆盖旧 1.2.51 结构配新脚本后的恢复、选择套餐后发布、重复发布拒绝、当前套餐点击切换、独立打包中心递归模块加载及管理资源不可访问。

本次不变更数据库、Key、授权方式、套餐权益、激活和客户构建记录；保留 1.2.54 的套餐版本关联与更新实时刷新。环境合同和授权桥 1.1.6 保持不变。
