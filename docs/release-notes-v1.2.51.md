# APPGOG打包授权系统 v1.2.51

## 套餐显示与管理

- 系统预置套餐的原名称“付费版”改为“定义版”；自定义名称不覆盖，已删除模板不会恢复。
- 授权列表套餐列只显示“更改套餐”按钮，当前套餐名称和删除状态放入弹窗，打开时读取最新可用套餐；没有目标套餐时明确提示并禁止空提交。
- 套餐删除/停用状态同步显示到更改套餐弹窗、管理详情与客户打包中心。已有授权保留原权益快照；手动切换按原有事务更新权益、撤销旧激活并记录审计。
- 打包卡片按服务端判断显示当前套餐是否可用，避免用发布分类冒充客户套餐。版本发布仍保留免费/付费分类。
- 两个中心返回标签页时刷新状态，接口不使用浏览器缓存，进行中的刷新不会吞掉修改后的刷新请求。

## 升级边界

新增幂等迁移仅修改code=paid且名称仍为付费版的模板名称，包括已删除的历史模板；不改授权Key、额度、快照、激活、域名或构建记录。桥保持1.1.6，环境合同不变。
