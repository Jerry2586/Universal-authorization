# APPGOG打包授权系统 v1.2.40

日期：2026-09-27

- 修复原生主题激活顺序：激活按钮先显示本地安装 Key 弹窗，成功后跳转后台在线固定 Key 页面；签名激活状态保存成功后才切换主题。
- 授权桥 1.1.0 安装独立宿主守卫，并备份 Xboard bootstrap。新包对主题读取、保存、启用及公开主题入口执行服务端签名、域名、安装身份和能力验证。插件停用或删除后仍拒绝受保护主题访问，保留原生后台恢复入口。
- 旧版无守卫验证信息的主题不在桥升级时强制锁死；必须重新构建安装新包才能获得完整服务端保护。数据库、现有授权、安装身份和主题设置保留。
- 已打开的主题后台在前台每 30 秒及重新聚焦时复查组件；读写设置前再验证。失效时锁定外层编辑器和预览，关闭顶层对话框，阻止继续保存。
- 授权与更新改为主题后台主内容区，沿用原导航字体；切换栏目恢复原编辑区域。普通用户页面不增加管理入口。
- 分离桥读取、安装、刷新和重载的限流桶。429 遵守等待时间，重试清除失败预取结果；429/5xx 不作为主题清理依据。
- 回归覆盖持久守卫、删除插件、恢复入口、旧包兼容、两阶段启用顺序、动态锁定及真实主题 ZIP 构建。首次接入和宿主文件保护边界见 xboard-activation-standard.md。
