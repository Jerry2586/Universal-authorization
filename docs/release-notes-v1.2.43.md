# APPGOG打包授权系统 v1.2.43

## 系统运维中的授权桥管理

- 新增独立卡片，连接指定 Xboard 后显示实际桥版本、最新签名桥版本、检查时间及独立执行日志。
- 提供检查更新、安全更新最新版本和修复当前版本。连接短期绑定当前管理员会话，密码提交即清空，远端 Token 不持久化。
- 升级仅接受正式发布清单验签及 ZIP 摘要通过的桥包；禁止降级、过期结果、目标重定向、内网地址及重复任务。
- 更新后核对插件与运行版本及原 Installation ID。中断或响应丢失不自动重放，不伪报成功或声称自动回滚。
- 授权桥 1.1.3 增加管理员修复接口和唯一新迁移，保留原身份、授权及主题设置。修复宿主注册及脚本，刷新缓存并重载；不支持原生后台无法启动的服务器恢复。

## 验证与部署边界

- 增加 HTTP 权限/CSRF、签名发布源、目标网络限制、任务生命周期、浏览器 UI 以及真实旧宿主文件重复升级的回归。
- 环境合同保持 Node 24、Caddy 2.10、Docker Compose 2.24+ 不变，平台源码和签名制品统一 1.2.43。
- 更新两个中心不会自动更新客户桥。首次未安装桥、已停用或站点 500 时须从原生 Xboard 恢复。
- 操作说明与验收范围：`docs/bridge-maintenance.md`。
