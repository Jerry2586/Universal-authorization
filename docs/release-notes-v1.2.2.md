# APPGOG打包授权系统 v1.2.2

发布日期：2026-09-24

## 本次修复

- 修复国内或受限网络服务器升级时卡在 `load metadata for docker.io/library/node` / `caddy` 的问题。
- 一键安装与升级在构建前真实探测 Node、Caddy 两个基础镜像；Docker Hub 不可用时自动切换 DaoCloud 公开维护的镜像路径。
- 自动选择必须同时验证两个镜像，成功后才同步写入保留数据的共享 `.env`；旧安装升级也会更新基础镜像字段。
- 用户显式指定的 registry mirror、Node 镜像或 Caddy 镜像保持最高优先级，失败时给出明确日志，不会静默覆盖。
- Docker 构建增加最多 3 次有限重试，并把镜像探测和构建输出保存到独立日志。
- 修改 Docker `daemon.json` 前自动备份原文件，修改后验证 Docker 服务恢复。
- 始终保持 TLS 校验，不配置 `insecure-registries`。

## 数据与升级保证

重复执行 README 中完全相同的一行命令即可升级。数据库、管理员账户和密码、授权 Key、公告与运营设置、上传源码、构建成品、签名密钥、证书状态和备份均继续保留；程序源码、前后端页面与部署脚本使用 v1.2.2 完整覆盖。
