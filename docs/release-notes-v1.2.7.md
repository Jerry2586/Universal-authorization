# APPGOG打包授权系统 v1.2.7

发布日期：2026-09-24

## 本次更新

- 客户交付工作台现在显示后端真实运行版本号，版本来自当前容器内的 `package.json`，不再由页面写死。
- 恢复客户工作台“交付步骤”，按授权验证、选择版本并构建、下载交付文件、安装并正式激活四步展示完整流程。
- 工作台公告从占据顶部的大横幅改为紧凑公告卡；长公告支持展开与收起，桌面端和手机端均保持清晰布局。
- 管理后台“公告中心”升级为“公告运营”，采用内容编辑器与客户工作台实时预览双栏布局，并显示标题/正文字数、启用状态和发布时间。
- 统一公告运营、客户工作台和侧栏版本信息的视觉层级，补齐窄屏响应式布局并保持克制的交互反馈。
- 增加页面合同与服务回归测试，确保真实版本号、交付流程、公告预览和展开控件不会在后续更新中再次丢失。

## 数据与升级

本版本不修改业务数据库结构。管理员账号和密码、授权 Key、公告内容、运营设置、签名密钥、上传源码、构建成品、日志和备份全部保持不变；程序源码、页面和后端按 v1.2.7 完整覆盖。服务器继续执行 README 中完全相同的一键命令即可升级。
