# APPGOG打包授权系统 v1.2.8

发布日期：2026-09-24

## 本次更新

- 重做管理后台“主题版本”工作区：增加版本统计、紧凑拖拽上传、版本号与名称自动识别、渠道/类型/公告编辑、版本搜索与状态筛选。
- 新增完整工单系统。客户可提交打包、构建、安装、授权和使用咨询，关联构建任务、设置紧急程度、上传截图或日志并连续回复。
- 运营后台新增工单队列、搜索筛选、优先级、管理员指派、状态流转、客户可见回复、内部备注、附件与审计记录。
- 工单附件仅允许 PNG、JPEG、WebP、TXT、LOG 和 PDF，单文件最大 10 MB；客户只能访问自己的工单，内部备注不会返回客户。
- 删除业务层面的历史版本回滚包、版本回滚配置和 Linux 公开回滚菜单。客户只可构建最新版本或重新构建当前已激活版本。
- 保留并加强安装器内部安全恢复：更新前完整备份，健康检查失败自动重试并恢复旧程序链接和旧健康镜像。
- 修复网页在线更新入口，按钮统一为“安全更新最新版本”；助手离线时显示 systemd 修复命令与 `appgog update` 备用入口。
- 更新助手服务增加固定工作目录、升级后重装启动、心跳等待和 systemd 失败诊断，避免页面长期显示“助手离线”。
- Linux `appgog` 菜单继续作为备用管理入口，更新文案与网页保持一致。

## 数据与升级

本版本新增工单、消息和附件元数据表，迁移使用 `CREATE TABLE IF NOT EXISTS`，不会删除或重建已有数据库。管理员账号和密码、授权 Key、公告、运营设置、签名密钥、上传源码、构建成品、日志和备份全部保留；程序源码、前端、后端、Docker 配置和安装脚本按 v1.2.8 完整覆盖。

服务器继续执行 README 中完全相同的一键命令即可升级。环境合同保持 Node.js 24、`node:24-bookworm-slim`、Caddy 2.10、Docker Compose 2.24+，支持 amd64 与 arm64。
