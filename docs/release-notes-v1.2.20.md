# APPGOG打包授权系统 v1.2.20

日期：2026-09-25

## 安装与更新

- 固定短命令首次安装，再次运行获取签名 Latest Release；不再根据当前目录误用旧源码。
- 终端更新和网页更新共用签名安装入口，清除继承的旧版本锁定，准确传递失败退出码。
- 相同版本仅在磁盘、镜像、环境一致且健康时跳过；拒绝降级；修复当前版本单独执行。
- 更新助手在部署期间持续刷新心跳，保留成功或失败结果；终端升级成功后重新加载新版菜单。
- Docker 健康检查核对授权中心、打包中心及其上游版本，防止错误版本被判为健康。

## 连通性与版本

包含 v1.2.18–v1.2.19 的管理登录、Key 登录、客户 ES Module 发布、客户端 IP、请求编号、错误合同、启动端口和运行版本展示修复。保留数据库、管理员、Key、业务文件和签名身份。

## 发布要求

正式发布须通过完整测试、Shell 语法、source/artifacts 合同、Ed25519 签名校验与 Ubuntu/Docker CI，并回下载七份 Release 附件验收。
