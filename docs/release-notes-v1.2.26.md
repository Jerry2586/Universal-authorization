# APPGOG打包授权系统 v1.2.26

发布日期：2026-09-25

## 本次更新

- 授权中心改为上下完整宽度布局：授权管理在上，授权列表在下，移除拥挤的左右分栏。
- 授权管理新增每日打包上限与总打包额度，可查看累计已使用、剩余额度和过去 24 小时使用数。
- 额度修改必须填写原因，并在同一数据库事务中写入授权事件和全局审计。
- 打包中心在服务端同时校验过去 24 小时额度与总额度；总额度为空时保持历史授权不限次数的兼容行为。
- 总打包额度不写入激活凭证，修改额度不会改变固定 Key、现有激活或授权签名契约。
- 统一修复首页、运营中心和打包中心的品牌 Logo 裁切显示。

## 数据与升级

- 升级只为 `licenses` 表追加可空的 `max_builds_total` 字段；旧授权默认不限总次数，原有数据库、账号、Key、激活、设置和构建记录不变。
- 迁移可重复执行，失败时不得删除数据库、业务卷或重新生成已有密钥。
