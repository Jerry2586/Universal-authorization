# 安全查杀中心 v1.2.69

授权后台「安全查杀中心」采用本机优先的十页界面。首页为盾牌、检查状态、全面检查、六个防护入口与最近动态；部署拓扑不占用首页，节点与云端连接信息放入设置。

## 页面与真实能力

| 页面 | 本版行为 |
|---|---|
| 安全首页 | 完整且及时的本机报告驱动覆盖、问题数量与模块状态 |
| 病毒查杀 | 手动调用固定范围完整检查，展示程序与业务文件的 ClamAV 结果 |
| 实时防护 | 展示定期巡检及响应准备结果；周期为五分钟 |
| 环境检查 | 展示系统、SSH、权限、TCP/UDP、路由、防火墙、进程及 CF 检查 |
| 网站与容器 | 展示文件摘要、固定配置、容器合同、获准镜像、SQLite 结构检查 |
| 隔离区 | 界面入口已提供，隔离记录与恢复/删除接口待接入 |
| 修复与恢复 | 展示恢复准备报告，跳转系统运维；网页一键事件恢复待接入 |
| 备份容灾 | 跳转已有备份运维；不可变异机灾备、干净宿主重建及 RPO/RTO 待建设 |
| 防护日志 | 展示本机代理返回的真实状态变化，可跳转系统审计 |
| 设置 | 展示本机接入说明和云端身份、健康、摘要与上报状态；网页连接编辑待接入 |

病毒引擎、CF 凭据、可信基线等需在 Linux 管理菜单正确配置。Windows UI 预览不具备 Linux 宿主代理，状态为不可用。完整性核验不等于通用恶意程序检测，也不能证明具有宿主 root 权限的攻击者没有伪造报告。

## 数据与操作边界

状态继续使用固定 25 项合同、证据摘要、时间、覆盖与历史校验。报告过期、不完整、代理不可用或历史不可用时不显示健康统计。原始报告仍可查看异常证据。安全字段通过 textContent 渲染；登出后清除界面中的报告，过期会话不能回填数据。

所有扫描按钮调用同一固定范围检查端点，不模拟扫描百分比或自定义路径扫描。仅收到真实 running 状态或正在提交检查请求时展示扫描动画。未接入的破坏性操作禁用。自动处置必须依据已配置的实际策略与证据，不能从界面文案推断已封控或已清理。

## 更新

安装器、环境和三种角色的短命令沿用现有机制。已安装服务器执行 appgog update 或菜单 9；分机授权与打包节点保持同一版本。升级保留数据库、身份、密钥、配置、上传、成品与备份。云端独立项目本轮没有发布变更。
