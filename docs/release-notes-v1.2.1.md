# APPGOG打包授权系统 v1.2.1

发布日期：2026-09-24。

## 热修复

- 修复直接使用 `scripts/docker.sh` 首次安装、启动、重启、回滚或恢复时，宿主机绑定的 `shared/update-control` 目录可能由 root 创建，导致容器内授权服务因无权创建请求目录而启动失败的问题。
- 所有 Docker 启动入口现在都会在业务容器启动前，以受限维护容器预创建 `update-control/requests`，统一修正为 UID 1000 所有并设置 770 权限。
- 保留 v1.2.0 的后台、Key、公告、上传、在线更新、版本化程序目录和数据保护功能不变。

## 验证

- Node 自动测试覆盖更新目录权限准备命令。
- GitHub Actions 执行真实 Docker 首装、构建、更新、加密备份、完整恢复和域名热重载。
