# APPGOG打包授权系统 v1.2.4

发布日期：2026-09-24

## 本次修复

- 修复从 v1.2.0 以前版本升级时，持久化身份缺少新增的 `LICENSE_ENCRYPTION_KEY`，导致新容器不断重启并报“无效的生产凭证”的问题。
- 对尚未保存加密完整 Key 的旧数据库，自动生成并持久化新的独立授权 Key 加密密钥。
- 迁移只补充新增字段；管理员身份、已有会话密钥、Worker 凭证、Delivery 加密密钥、Ed25519 签名密钥和历史授权数据均保持不变。
- 如果数据库已经存在加密完整 Key，但原加密密钥缺失或无效，则禁止自动换钥并要求恢复原身份配置，避免历史完整 Key 永久无法解密。
- 新增旧身份安全迁移和已有密文拒绝换钥测试。

## 升级方式

服务器直接重新执行 README 中相同的一键命令。v1.2.3 失败后已经自动恢复的旧服务可以原地升级，无需删除容器、数据卷、数据库或配置。
