# APPGOG打包授权系统 v1.2.42

## APPGOG 卡片单入口

- 授权桥版本 1.1.2。受保护主题卡片隐藏原生“主题设置”“激活主题”按钮，在底部保留一个“激活 / 授权管理”入口；删除图标及其他未受保护主题保持原有操作。

- 自有入口继续先打开本地激活弹窗，后续在线激活、服务端 423 拦截、安装身份和授权状态不变。

## 验证范围

- 浏览器回归覆盖原生按钮隐藏且节点保留、删除操作、其他主题、已启用状态、带翻译标签的按钮文本、整个按钮区重建、窄屏布局以及无提前启用请求。
- 此回归不是完整浏览器翻译扩展验收，不宣称排除了所有 insertBefore 错误；客户服务器仍需核验实际桥版本及页面状态。
- 平台与环境合同同步按 1.2.42 发布，Node/Docker/Caddy 要求未变。
- 更新两个中心不会自动升级已经部署的客户桥。客户 Xboard 需通过官方插件升级到 1.1.2，并确认桥健康接口实际返回该版本。
