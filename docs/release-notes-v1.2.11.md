# APPGOG打包授权系统 v1.2.11

发布日期：2026-09-25

## 本次更新

v1.2.11 完成公司级重构蓝图的 Phase 1：管理后台和客户打包中心不再共用一个巨型入口与全局状态，而是拥有独立入口、独立状态实例和独立页面控制器。通用会话、导航、通知、弹窗和 API Client 保持共享，业务页面不能直接操作另一入口的状态或调用另一身份的接口。

- 管理端改为 `/assets/admin-portal.js`，客户打包端改为 `/assets/customer-portal.js`；
- 新增共享 `portal/shell.js`，统一登录、退出、会话恢复、CSRF、导航和错误提示；
- 客户构建、授权域名、公告和客户工单集中在 `customer-page.js`；
- 管理端按页面编排、总览渲染和版本上传继续拆成三个小模块；
- 原 `/assets/portal.js` 保留为旧页面缓存兼容分发器，不再持有业务逻辑；
- 所有页面写操作继续保留提交中、成功和失败状态，上传仍支持点击与拖拽；
- 增加状态实例隔离、入口隔离、身份接口边界和模块体积回归测试；
- 本地真实浏览器已验证两个入口只加载各自模块且无控制台错误。

## 数据与 API 兼容

本次更新不修改数据库结构和 `/api/v1`、`/web/*` 业务字段，不改变现有管理员、客户、License Key、授权、工单、公告、上传、构建成品、日志、备份或签名密钥。升级仍完整覆盖程序文件并保留全部持久数据；失败时继续保存诊断并恢复原健康版本。

## 升级

已安装环境执行：

```sh
appgog update
```

升级后浏览器如仍持有旧 HTML，会由兼容入口自动分发到新的管理端或客户入口；正常刷新后直接使用独立入口。
