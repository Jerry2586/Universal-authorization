# APPGOG打包授权系统 v1.2.28

日期：2026-09-26

- 分离授权、套餐、公告、构建与工单入口，统一运营和客户打包中心样式、版本展示及弹窗行为。
- 增加套餐创建、修改、停用和访问级别；既有授权保留能力快照，停用套餐阻止新的分配。
- 构建按意图和基础版本识别重复请求，支持作废与超时恢复；已经生成成品的构建仍计入额度，文件删除失败可重试。
- Worker 增加网络阶段诊断、连接与传输超时，便于定位源码下载和成品上传故障。
- Xboard 授权桥升级至 1.0.1，自动安装支持自定义管理路径；升级后必须重新核验桥版本，保留安装身份。
- 三个主题入口使用同一白色两阶段激活界面，固定 Key、一次性 Install Key、Receipt、域名与 Installation ID 语义保持不变。
- 安装窗口过期清理由 Xboard 后台调度执行，删除前向授权中心确认，并核对安装包身份；旧任务不能删除后来安装的同名新包。手工清理接口要求管理员会话。

## 升级与运行要求

安装、更新使用同一稳定入口，程序和环境按发布合同更新，数据库、账号、密钥、授权、设置和业务文件保留。Xboard 必须正常运行其 Laravel 调度器且启用授权桥，才能在浏览器关闭时检查安装窗口；调度每分钟执行。授权中心不可达、清理未获确认或无安全备用主题时保留文件并记录诊断。

安装窗口超时清理与已激活后的撤销是不同状态：撤销在后续服务端校验时锁定，现有签名凭证存在有效期；本版不宣称离线即时撤销或已激活主题自动删除。

## 验证

全量 Node 测试包含实际 PHP 授权桥清理回归（9 个场景）。运行测试需 PHP 8.2+，Windows 可使用 APPGOG_TEST_PHP 指定 php.exe。真实 APPGOG/Xboard ZIP 通过 verify-theme-fixture.js 校验三入口注入、混淆、篡改拒绝和两阶段激活。正式发布必须通过 Ubuntu/Docker 首装、升级、备份与恢复 CI，并回下载七附件校验签名和哈希。
