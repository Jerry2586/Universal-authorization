# APPGOG打包授权系统 v1.2.5

发布日期：2026-09-24

## 本次修复

- 修复旧生产数据库已经记录基线迁移、但 `admin_users` 实际缺少 `deleted_at` 与 `deleted_username` 时，新容器启动失败并报 `no such column: deleted_at` 的问题。
- 新增独立的数据库兼容迁移，不再假定“已有迁移记录”等于“实际表结构完整”；启动时逐表核对并只追加缺少的兼容列。
- 迁移不重建表、不删除字段、不覆盖已有值；管理员账号和密码、授权 Key、公告、设置、上传文件、构建成品以及历史业务数据全部保留。
- 保留原有基线迁移记录，并为兼容补列单独登记版本，确保重复启动安全且不会重复修改。
- 新增真实旧库回归测试：模拟已有基线记录但管理员表缺少后续列，验证自动补齐、管理员身份保留以及 Repository 可以正常初始化。

## 升级方式

服务器直接重新执行 README 中相同的一键命令。v1.2.4 升级失败后已经自动恢复的旧服务可以原地升级，无需删除容器、数据卷、数据库或配置。
