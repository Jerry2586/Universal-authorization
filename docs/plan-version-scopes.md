# 套餐与版本关联（v1.2.54）

授权列表只显示“更改套餐”操作，打开后显示当前套餐和所有有效候选。切换更新该 Key 的额度与能力快照，固定 Key 不变；原激活按既有流程撤销。打包中心显示“你的套餐：实际套餐名称”，版本卡片同步实际名称。

## 发布与可见性

新版本必须选择至少一个有效、非 legacy 套餐，可以多选。版本目录允许“设置套餐”修改已发布版本的关联，无需再次上传 ZIP。官方 HTTP 发布入口拒绝空或无效套餐；前端展示不能替代后端许可校验。

客户仅能查看与自己有效套餐关联的版本；构建授权和票据领取使用同一 Entitlement 校验。套餐停用、删除或取消版本关联后，新构建与旧票据领取均不可绕过。公开发布公告不携带客户身份，不等于构建许可。

## 旧版本升级

已有版本首次升级按仍有效套餐历史范围填充关联：free 对应免费，paid_only 对应付费，旧 paid 对应两者。没有有效套餐时关联为空，由管理员创建套餐、迁移 Key 并设置版本关联。已删除套餐不会被恢复，客户不会被自动改套餐。历史已登记版本保留旧范围兼容；新发布的应用服务及 HTTP 入口都必须明确选择套餐。未登记版本在签发和领取构建票据时均被拒绝。

## 删除与命名

套餐下只要有任意 Key 就不能删除，暂停或撤销的 Key 同样计数。必须先更改全部关联 Key 的套餐或按既有流程永久删除 Key。删除与审计在同一事务中完成。

v1.2.51 的默认“定义版”误改名在本次恢复为“付费版”；用户通过套餐编辑有审计记录明确命名“定义版”时保留。其他自定义名称保持不变。

## 边界

Product 保存版本的套餐关联，调用 Entitlement 公开端口验证套餐；Entitlement 统一决定版本权益，Packaging 在创建和领取票据时执行。UI 只消费结果，不直接决定授权。域名绑定、迁移、两阶段激活和加密机制不在本次修改范围。
