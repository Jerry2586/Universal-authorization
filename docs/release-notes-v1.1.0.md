# APPGOG打包授权系统 v1.1.0

发布日期：2026-09-23。

## 本次需求与开发阶段

### 1. 账号与后台 UI

- 管理员和客户登录页移除“返回首页”按钮及点击区域。
- 管理后台与打包中心统一把退出入口放到右上角。
- 管理员首次密码和新建成员初始密码限制为六位数字。
- 管理员可在用户中心校验旧密码后自行改密；改密后旧会话全部失效。
- 普通管理员支持软删除并释放用户名；所有者和当前账号不可删除，审计记录保留。

### 2. 真实主题上传与版本识别

- 主题 ZIP 支持点击选择和拖拽上传，显示文件名、大小、状态与真实进度。
- 限制 ZIP 格式和 128 MiB，网络、格式、超限和安全检查失败均显示明确原因。
- 自动从 ZIP 内 `config.json`、文件名和根目录识别版本号与版本名称。
- 多个来源互相冲突时拒绝发布；确实无法识别时允许人工填写。
- 修复版本管理区域横向溢出和空状态布局。

### 3. 固定 Key、域名换绑、冷却与公告

- 授权 Key 不提供删除接口；撤销只改变状态并保留数据库与审计记录。
- 客户可按后台冷却时间自助即时换绑域名，无需管理员审批。
- 换绑保持原固定 Key，增加 generation，立即撤销旧 Activation 和未使用 Install Receipt；新域名重新输入原 Key 激活。
- 管理员主动换域名不受冷却限制；冷却设置为 0 时关闭限制。
- 后台新增运营公告标题、正文、启用状态和发布时间，客户打包页在构建前展示。

### 4. 网页与 Linux 控制面分离

- 部署域名、授权服务、客户登录、打包中心、新构建和 Worker 开关在网页中只读。
- 上述部署级配置只允许通过 Linux `appgog config` 和 `appgog services` 修改。
- 网页强行提交部署字段时返回 `DEPLOYMENT_SETTING_READ_ONLY`。

### 5. 一键部署、国内网络容灾与可信发布

- 新增顶层 `install-docker.sh`；源码目录内执行 `sudo sh install-docker.sh` 即可安装或升级。
- 安装器自动检测并补齐系统工具、Docker、Compose 和 Buildx，检查端口、DNS、防火墙和公网 HTTPS。
- `--source auto|china|github` 支持国内源优先与 GitHub 容灾；完全断网使用完整 `.run`。
- 支持一次性 Cloudflare Token 自动创建或更新两个 DNS A 记录，Token 不写配置和日志。
- 支持 Docker registry mirror 以及 Node/Caddy 国内基础镜像。
- 重复执行相同安装命令自动进入升级流程，保留 `.env`、runtime、数据库、备份和密钥；切换失败自动回滚。
- 发布 ZIP、`.run`、两份 SHA-256、`release-manifest.json` 和 Ed25519 清单签名。
- 下载器只接受签名清单指定的版本和文件，并在安装前校验 ZIP SHA-256。
