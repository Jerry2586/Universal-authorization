# APPGOG打包授权系统 v1.2.3

发布日期：2026-09-24

## 本次修复

- 修复生产数据较多或服务器较慢时，新容器内部服务只有 15 秒启动时间，升级可能被过早判断为 `unhealthy` 的问题。
- 授权中心、客户打包中心和 Caddy 的单项启动等待提高到 120 秒，Compose 整体健康等待提高到 360 秒；仍可通过环境变量在安全范围内调整。
- 新版本首次健康检查失败会自动停止并重试一次，第二次仍失败才执行原版本回滚。
- 回滚前自动保存容器状态、OOM/退出码、Docker 健康检查历史和最近 300 行容器日志到 `shared/logs/startup-failure-*.log`。
- 容器启动入口不再吞掉异常，会明确输出启动超时、最后 HTTP 错误和堆栈。

## 数据安全

更新流程仍先创建加密完整备份。数据库、管理员账号和密码、授权 Key、公告与设置、上传源码、构建成品、签名密钥与证书状态保持不变；启动失败时原版本自动恢复。
