# APPGOG打包授权系统 v1.2.48

## 客户包保护

- 授权中心对最终构建清单加签，覆盖页面、业务资源、授权运行时、内置桥 ZIP 与关键配置。重算文件摘要/HMAC不能替代内容签名。
- 浏览器和授权桥拒绝新包缺少签名、内容变化和签名无效；旧签名身份保留兼容，不要求所有客户重新激活。
- 授权运行时与桥前端 JS 追加混淆；正式客户包移除开发预览页，独立 HTML 入口进入保护扫描。
- 授权桥 1.1.6 通过新迁移更新持久化 Guard 并重载 PHP，保留原安装身份、私有状态和恢复备份；禁止后续包静默替换已登记公钥。
- 新保护需重新构建客户主题包，不改变主题业务版本号；PHP 源码和可解压 ZIP 是兼容运行需要，不承诺百分百防逆向。

## 产品管理与界面

- 运营中心增加独立产品管理，可创建、编辑名称、归档和恢复；产品编码不可修改。签发授权与发布版本使用明确的产品选择。
- 归档阻止新签发及新版本发布，保留已有客户激活与更新权益；同版本号按产品隔离。
- 打包中心安装指南改为三步主流程和紧凑恢复分区，保留窄屏适配。
- 作废构建下载返回明确“已作废”说明。

## 升级与验证

环境合同保持原 Node、Caddy、Compose 与架构要求。数据库、管理员、授权、设置、签名身份、上传与历史成品必须保留。新包签名使用原 Package 签名用途，禁止自动更换生产密钥。

发布前必须通过全量测试、真实主题 ZIP 构建与两阶段激活、PHP 跨语言验签、混淆脚本浏览器验证及发布合同检查；正式 Release 仍需 Docker CI 与七附件回下载验签。工作区版本号不代表已经发布或部署。
