# APPGOG打包授权系统 v1.2.64

候选版本：授权与打包角色均安装受限的宿主检查代理；启动后执行首次扫描，此后每五分钟扫描固定六项发布文件及有限 Linux 配置。手动检查与周期检查共享锁和一分钟冷却，不并发运行。节点向独立云端上报脱敏的检查时间、状态和各等级计数；云端分别标记自报与独立 HTTPS 探测。授权后台同时展示两个节点的宿主检查状态，缺失、过期和连接失败不显示为健康。

扫描仍只覆盖固定清单，不覆盖业务数据或整个宿主机；基线是本地安装生成，升级差异须人工核验。节点失守时可伪造自报，因此不以自报结果自动封控或重建。Linux systemd 与 ClamAV 实机、两/三机身份、备份和恢复演练、签名正式发布及生产部署尚待验收。
