# APPGOG打包授权系统 v1.2.59

- 授权桥 1.1.10 修复 Xboard 禁用与卸载生命周期混用。禁用保留安装身份与激活状态；正式卸载在宿主删除插件记录后清理集成，不能依赖 Laravel 恰好回滚最新插件迁移批次。
- 常驻宿主 Guard 对成功的原生卸载/删除响应补充清理，兼容插件记录已缺失的删除路径；失败、未授权和其他插件操作不触发清理。卸载后已加载的 Guard 不再拦截请求或重建主题登记。
- bootstrap 只移除已知注册块，兼容 LF/CRLF，保留站点后续配置；清除桥专属目录并安排运行时重载。普通源码仓库与业务数据不变。
- 唯一迁移 2026_10_01_000017_removal_lifecycle 刷新旧宿主集成，升级保留身份；完全卸载会清除桥本机身份和凭据，再安装成品需要重新完成安装流程。

## 已卸载旧桥的恢复

中心更新不会自动清理客户服务器。先在 Xboard 上传本版本桥、安装并启用，使新的迁移和宿主清理逻辑生效，再通过原生插件管理正式卸载/删除。随后上传官方同名普通源码包，检查设置、启用和首页。若运行时未成功重载，按日志重启 Xboard 应用服务。不得删除 Xboard 数据卷、APP_KEY 或用户主题设置。

## 验收

覆盖真实 cleanup 调用顺序、禁用不清除状态、无迁移回滚卸载、已缺失插件记录的删除、失败/未授权不清理、常驻请求放行、同名普通源码设置/启用/首页及重启注册检查。
