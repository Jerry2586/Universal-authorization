# APPGOG打包授权系统 v1.2.61

新增授权后台安全状态页面和服务端云端状态接口。增加独立的证书与令牌双重认证上报、配对及只读诊断脚本；后端仅展示独立云端监测器的状态，文件摘要监测不能代替恶意软件查杀。

此版本的同机业务部署保持原有升级和数据卷保留流程。分机部署与独立云端中心的生产安装尚未完成真实 Linux 首装、升级和断线验收，未通过门槛前不得将本版本标为已交付。正式发布仍按仓库强制签名与 CI 流程。

私有仓库更新：支持由 root 权限保护的只读令牌访问 GitHub Release API，仍逐项验证发布清单 Ed25519 签名及制品 SHA-256。旧版更新助手需先通过正式签名离线包升级。
