# APPGOG打包授权系统 v1.2.71

日期：2026-10-04。

授权运营中心与客户打包中心统一升级为简洁的卡片式界面：紧凑导航、细线图标、分层表格和清晰的状态颜色。登录、表单、上传、工单弹窗与手机页面使用同一套视觉样式。

两个中心均可选择日间、夜间或跟随系统外观。偏好在刷新后保留，同源标签页同步，系统模式响应系统主题变化；浏览器禁止存储时仍可在当前页面切换。主题菜单支持键盘操作，移动端保持原有抽屉导航。独立打包中心同时提供所需外观脚本。

授权、额度、套餐和打包权限继续由原有服务端接口判断；此次升级保留账号、数据库、Key、签名身份、上传、成品、备份与三种部署角色。铁幕安全及玄武引擎在独立安全仓库维护。

本地全量回归与真实登录的浏览器验收已通过。正式发布继续执行 Ubuntu/Docker 首装、构建、升级、恢复以及 Ed25519 签名和七附件回下载验证，结果以对应 GitHub Actions 记录为准。
