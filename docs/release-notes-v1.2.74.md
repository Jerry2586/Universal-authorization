# APPGOG打包授权系统 v1.2.74

日期：2026-10-07。

管理员初始密码、后台新建管理员密码和用户中心修改密码统一支持 6–128 个字符，可使用字母、数字和符号，不再强制固定六位数字或数字键盘。

服务端统一校验密码类型和长度，创建、修改、登录和当前密码确认都会拒绝过短、超过 128 个字符及非字符串输入，避免前端限制被绕过，并在进入密码派生计算前快速拒绝异常输入。128 字符上限用于限制密码派生函数的异常输入成本。

管理员登录和当前密码校验不再把 JSON 数字隐式转换成字符串，防止非字符串输入被当成合法密码，并确保“新密码不能与当前密码相同”的判断不可被类型差异绕过。

管理员创建、停用、改密、删除、会话撤销与对应审计记录现已处于同一 SQLite 事务；审计写入失败时会整体回滚，不再留下已变更但缺少审计记录的账号状态。Identity 服务缺少事务执行器时会立即拒绝启动，禁止静默退化成非事务写入。

修改密码后继续撤销该管理员的全部旧会话并要求重新登录。回归测试覆盖混合字符密码登录、旧密码失效、多个旧会话撤销，以及创建和修改接口的非法输入。

本地发布前仍需通过全量测试、发布合同、Shell 语法检查和正式产物验签；GitHub CI、签名发布和七附件回下载验证结果以对应流水线为准。
